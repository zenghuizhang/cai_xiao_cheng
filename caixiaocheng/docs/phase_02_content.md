## 二、卡片 JSON 格式（严格对齐你给定的结构）

```json
{
  "id": "C1_001",
  "chapter": 1,
  "order_index": 1,
  "title": "通货膨胀：你的钱正在偷偷缩水",
  "daily_analogy": "想象你存了10万块在罐子里埋在地下。10年后挖出来，数字一分没少，可原来能买一辆车，现在可能只够买几个轮胎。就像冰箱里的蔬菜，你没动它，它自己却慢慢烂掉了。",
  "core_knowledge": "通货膨胀，简单说就是物价普遍上涨、钱越来越不值钱……",
  "illustration_note": "一张100元纸币慢慢变轻、旁边的蔬菜标价牌数字跳涨的轻动画",
  "glossary_terms": ["通货膨胀", "购买力"],
  "points": 10,
  "difficulty": 1,
  "related_quiz_id": "QZ_C1_01"
}
```

- 每张卡片都有 `id / chapter / title / daily_analogy / core_knowledge / illustration_note / related_quiz_id`；
- 额外增加了 `order_index`（信息流排序）、`glossary_terms`（文中可点术语）、`points`（积分）、`difficulty`（1–3）字段，均为阶段一 Schema 中已设计的列；
- 测验题包含 `right_reply` / `wrong_reply` 俏皮话字段（如「哎呀，这是90%新手都会踩的坑哦，记住啦！」），用于答错时的情绪反馈。

## 三、章节内容要点

### 第 1 章 · 钱的世界观（15 节）
覆盖必含概念：**CPI、通货膨胀、购买力、72法则**。
线索：钱藏床底会缩水 → CPI 是菜价小账本 → 名义 vs 实际收益 → 活期/定期/国债/银行理财的区别 → 存款保险 → 利息是钱的租金 → 单利复利 → 72法则 → 跑赢通胀 → 理财≠炒股。
代表类比：冰箱里的蔬菜（通胀）、居委会大妈的菜价账本（CPI）、手机电池老化（购买力）、腌咸菜（定期）、国家打的借条（国债）、自助火锅（银行理财不保本）、雪球（复利）。

### 第 2 章 · 四大家庭理财工具（25 节）
- **股票 7 节**：买股票=入股奶茶店；分红与价差；股价随供需波动；个股风险；市盈率 PE=几年回本；散户为何易亏；指数=整条街平均水平。
- **债券 5 节**：债券=借条；国债/地方债/公司债的三六九等；价格与利率的跷跷板；债券基金也会跌；债券是防守队员。
- **基金 7 节**：凑份子请大厨；货币基金=零钱罐；混合/股票基金；指数基金=买下整条美食街；净值=披萨每小块价格；费率侵蚀；主动 vs 被动。
- **保险 4 节**：保险=灭火器；保障型 vs 理财型；四张保障型保单；买保险三个坑。
- 收尾 2 节：风险排行榜（步行→摩托）、给每笔钱派好岗位。

### 第 3 章 · 打败人性的定投策略（20 节）
覆盖必含概念：**微笑曲线、平均成本法、止盈不止损**。
包含：复利与 72 法则实操、定投纪律、平均成本法、微笑曲线、下跌不停扣、止盈不止损、仓位管理、股债搭配、再平衡、长期主义、短期投机危害、闲钱投资、10%工资法则、**定投模拟器说明（C3_015，明确写出年金终值公式 `FV = PMT × [((1+r)^n − 1) / r]`，供阶段三 Dart 实现）**、宽基选择、3-5年期限、8%只是假设、少看账户、极简定投计划 5 要素。

### 第 4 章 · 避坑指南与认知偏差（20 节）
覆盖必含概念：**幸存者偏差、羊群效应、沉没成本**。
还包含：追涨杀跌、损失厌恶、锚定效应、过度自信、FOMO、保本高息庞氏骗局、荐股群杀猪盘、P2P/空气币、查持牌机构、看新闻姿势、牛熊末期特征、投资日志、能力圈、暴跌应急清单、被骗维权流程，最后以「慢慢变富」四句心法收尾。
