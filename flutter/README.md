# 财小橙 · 7 天投资认知启蒙

> 一个给零基础小白的投资认知启蒙 App：**纯本地、零后台、零交易**。
> 用「买菜算账」「开奶茶店」的大白话，7 天搞懂通胀、理财工具、定投和防骗。

技术栈：**Flutter (Dart) + SQLite (sqflite) + Provider**。所有课程内容以 JSON 放在 `assets/data/` 下，首次启动灌入手机本地 SQLite。

---

## ⚠️ 免责声明（请先读）

- 本 App 是**教学工具**，不是理财软件。App 内**没有开户、没有实盘买卖、没有实时行情/K线**。
- 所有收益率、通胀率、模拟涨跌、历史场景均为**假设性教学示例**，不构成任何投资建议、收益预测或招揽邀约。
- 定投计算器使用「固定年化、月末投入」的理想公式，真实市场有涨有跌，结果仅用于理解原理。

## 产品设计概览

| 阶段 | 主题 | 段位 | 果实 |
|---|---|---|---|
| Lv1 | 钱为什么会变薄（通胀） | 青铜小白 | 🍊 看懂通胀 |
| Lv2 | 常见工具怎么选（存款/债/基/股） | 白银学徒 | 🥝 分清工具 |
| Lv3 | 定投是什么、怎么开始 | 黄金规划师 | 🍋 掌握定投 |
| Lv4 | 识破骗局与建立纪律 | 铂金守心人 | 🍎 识破骗局 |

### 核心交互

- **首启引导**：3 页滑动介绍（我是谁/学什么/三个承诺），完成后进主界面，可跳过。
- **小红书式卡片学习**：右滑「懂了」+积分、左滑「没懂」进复习队列；正文 18px、行高 1.8，大字好读。
- **复习队列**：首页「待复习 N 张」入口，卡片流复习——右滑「这次懂了」移出队列 +5 积分，左滑「再想想」留队下次再战。
- **闯关测验**：每章 8 题，答对 ≥80% 解锁下一章；答错有小橙人安慰 + 大白话解析。
- **模拟人生**：穿越到 1990/2008/2015 等年份做选择，看不同选择的假设结果（不接真实行情）。
- **定投计算器**：月投/年化/年数三个滑块，本地纯 Dart 实时算终值，附公式说明。
- **复利计算器**：本金/年化/年数三个滑块，复利终值 + 通胀购买力对照 + 72 法则；已测风险画像时显示建议股债配置。
- **风险测评**：5 题测出保守/稳健/进取画像，结果入库，显示在「我的」页并影响计算器建议（可重测）。
- **每日 3 分钟早餐挑战**：3 道判断题，连签得积分。
- **市场暴跌演练**：一个红色按钮，模拟本金 −20%，配上「这时候该怎么做」的心理建设。
- **经典书架**：16 本投资经典（《小狗钱钱》《富爸爸穷爸爸》《漫步华尔街》《聪明的投资者》《金钱心理学》《持续买入》《滚雪球》《巴比伦最富有的人》《投资最重要的事》《共同基金常识》《穷查理宝典》等）的大白话导读，按入门/进阶/高阶分组，含核心理念、金句、适合谁、阅读路径。均为原创摘要，标注作者并提示「支持正版」。
- **悬浮查词**：任何页面点「查词」，231 个金融词一句话读懂，全部带生活类比。
- **认知成长树**：每通关一章，树上结一个果实，段位从青铜升到铂金。

视觉：暖橙 `#FF8C42` + 奶白 `#FFF8F0`，**刻意避免股票软件的大红大绿作为主基调**。

## 打包 APK（正式交付）

按要求使用分架构打包，产物更小：

```bash
flutter build apk --split-per-abi --release
```

产物位于：

```
build/app/outputs/flutter-apk/
├── app-armeabi-v7a-release.apk    # 32 位老机型
├── app-arm64-v8a-release.apk      # 主流 64 位机型（绝大多数现代手机）
└── app-x86_64-release.apk         # 模拟器
```

> 直接安装 `app-arm64-v8a-release.apk` 即可覆盖绝大多数真机。
> 若需要单包通用 APK：`flutter build apk --release`。

应用**不申请联网权限**（无 `INTERNET`），所有数据存于设备本地 SQLite，卸载即清除。

## 如何更新课程内容（不改代码）

1. 编辑 `assets/data/knowledge_base.json`，按现有结构增删卡片/题目/模拟/词条。
2. 把 JSON 顶层 `meta.content_version` 加 1（例如 `"1"` → `"2"`）。
   - （当前版本在首启时灌入；如需支持已装机用户的热更灌库，可在 `DatabaseHelper._open` 的 `onUpgrade` 中根据 `content_version` 重新执行 `_seedFromAssets`，框架已预留。）
3. `flutter build apk --split-per-abi --release` 重新打包即可。

书籍只放**原创大白话导读**（核心理念、金句、适合谁、阅读路径），标注书名与作者，不复制原文；顶层 `books_note` 字段是「支持正版」提示。

### 内容规模（已达标 · content_version=7）

- 知识卡 **120** 张（C1×25 / C2×35 / C3×30 / C4×30）✅ ≥80
