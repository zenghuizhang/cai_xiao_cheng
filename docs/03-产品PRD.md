## 1. 产品目标

帮助投资小白在投入一分钱之前，建立体系化、风险意识优先的投资认知。学完后用户应能：

1. 说清楚通胀、复利、风险与收益的关系；
2. 看懂储蓄、债券、基金、股票等常见工具的本质与风险等级；
3. 理解指数基金与定投为什么适合新手；
4. 懂得资产配置的基本思路与自己的风险承受力；
5. 识别 80% 的常见理财骗局和认知偏差；
6. 知道第一步该做什么（应急金、账户、小额定投），并且不会盲目 all in。

## 2. 功能架构

```
财小苗
├── 引导页（首次启动）
│   ├── 欢迎（小苗 + 3 屏价值主张）
│   └── 进入应用
├── Tab 1 学习
│   ├── 学习路径总览（7 章时间线 + 总进度环）
│   ├── 章节详情（小节列表 + 章进度）
│   ├── 课程正文（比喻/段落/要点/术语卡）
│   └── 小节测验（2-3 题，即时反馈，通过解锁下一节）
├── Tab 2 工具箱
│   ├── 复利计算器（滑块 + 增长曲线）
│   ├── 定投计算器（滑块 + 本金/收益对比柱）
│   ├── 通胀缩水计算器（购买力对比）
│   ├── 风险承受力测评（8 题 → 风险类型 + 配置概念）
│   └── 术语词典（搜索 + 分类 + 人话解释）
├── Tab 3 我的
│   ├── 学习数据（完成章/节数、测验正确率、学习天数）
│   ├── 成就徽章（6 枚，达成条件解锁）
│   ├── 每日一签（投资格言/反思维）
│   ├── 重置进度
│   └── 关于与免责声明
└── 全局
    ├── 术语点按弹层（任何课程中带下划线的术语）
    ├── Toast / 反馈
    └── 硬件返回键（页面内回退）
```

## 3. 功能需求详述

### 3.1 引导页（Onboarding）

- 触发：首次启动（本地无 `onboarded` 标记）。
- 3 屏可横向滑动卡片：
  1. 「我不荐股」——只讲认知，不推代码；
  2. 「我不碰你的钱」——无交易、无登录、无账号；
  3. 「随时离线」——内容全在本地，不收集任何数据。
- 底部跳过 / 下一步 / 开始使用按钮。
- 完成后写入 localStorage，不再出现。

### 3.2 学习（Tab 1）

#### 3.2.1 学习路径总览

- 顶部问候语（按时段：早上好/下午好/晚上好）+ 一句小苗提示。
- 总进度条与百分比。
- 7 个章节节点组成的竖向时间线，每个节点展示：
  - 序号圆牌（已完成绿色对勾 / 进行中橙色描边+脉冲 / 未解锁灰色）
  - 章节标题、一句话简介、小节数、本章进度
- 章节按顺序解锁（上一章全部小节测验通过后解锁下一章）。
- 「重置进度」在「我的」中提供二次确认。

#### 3.2.2 章节详情

- 顶部显示章节封面（SVG 插画）、标题、简介、章进度。
- 小节列表：序号、标题、预计时长、难度星级、完成对勾。
- 已完成小节可复习；未解锁小节置灰。

#### 3.2.3 课程正文

- 内容块类型：
  - `hero`：比喻式开场（带底色卡片）
  - `p`：正文段落
  - `point`：要点引用块（绿色竖线）
  - `warn`：风险提示块（红色边框 + 警示图标）
  - `term`：行内术语（虚线下划线，点按弹释义）
  - `list`：要点列表
  - `figure`：SVG 示意图
- 文末显示「开始 N 道小测验」按钮；已通过则显示「复习测验 ✓」。

#### 3.2.4 小节测验

- 每节 2–3 道单选题。
- 选择后立即判定：正确绿色 + 小苗肯定；错误红色 + 正确答案 + 简短解释。
- 全部题目作答后给出得分。通过线 100%（新手阶段要求全对以强化记忆）；未通过可重做。
- 通过后：本节标记完成、更新进度、若为章节最后一节则解锁下一章并可能触发成就。

### 3.3 工具箱（Tab 2）

#### 3.3.1 复利计算器

- 输入：初始本金、每月投入、年化收益率（%）、投资年数（滑块，范围 0–50）。
- 输出：期末总额（数字滚动）、本金合计、收益合计、收益占比。
- 图表：SVG 堆叠面积/折线图，区分本金 vs 收益。
- 默认值：本金 0、月投 1000、年化 8%、30 年。
- 底部固定风险提示：「历史收益不代表未来，年化 8% 仅为示例」。

#### 3.3.2 定投计算器

- 输入：每月定投额、预期年化、定投年数。
- 输出：期末资产、累计本金、累计收益；并显示「如果一次性投入」对比（教育点：定投平滑成本）。
- 图表：本金/收益对比柱状（最后一年）+ 逐年折线。

#### 3.3.3 通胀缩水计算器

- 输入：当前金额、年通胀率、年数。
- 输出：N 年后的购买力（相当于今天的多少钱）、缩水百分比。
- 教育点：让用户体感「现金趴在活期会慢慢变毛」。

#### 3.3.4 风险承受力测评

- 8 题，覆盖：投资期限、可承受亏损比例、收入稳定性、投资经验、波动情绪反应等。
- 每题 4 个选项对应分值；最后给出类型：保守型 / 稳健型 / 平衡型 / 进取型。
- 结果页：小苗形象、类型解释、典型资产配置概念（货币/债券/权益的比例，仅示意非建议）、一句提醒。
- 结果可重测；不做「推荐具体基金」。

#### 3.3.5 术语词典

- 至少 40+ 条术语，按分类（基础概念/基金股票/风险收益/行为金融/防骗）。
- 搜索框实时过滤（支持拼音首字母？v1 用中文标题+别名模糊匹配）。
- 每条：术语名、一句话定义、人话解释/比喻、举例。

### 3.4 我的（Tab 3）

- 学习数据卡：已完成章节数 / 小节数、测验正确率、连续学习天数（按打开日期算）。
- 成就：
  1. 🌱 破土而出 —— 完成第 1 节
  2. 📚 初窥门径 —— 完成第 1 章
  3. 💧 复利信徒 —— 使用过复利计算器
  4. 🛡️ 防骗卫士 —— 完成「避开镰刀」章
  5. 🎯 知己知彼 —— 完成风险测评
  6. 🌳 财商小树 —— 学完全部 7 章
- 每日一签：从内置格言数组按日期取一条（不联网）。
- 重置进度（二次确认弹窗）。
- 关于与免责声明（版本号 + 教育用途声明 + 不构成投资建议）。

## 4. 内容大纲（7 章）

| 章 | 标题 | 小节数 | 核心信息 |
| --- | --- | --- | --- |
| 1 | 理财先理脑 | 5 | 为什么要理财、通胀是什么、复利的力量、钱的三个账户、别急着买产品 |
| 2 | 认清风险 | 4 | 风险与收益同源、波动≠风险、你能亏多少、能力圈 |
| 3 | 常见工具 | 6 | 现金/储蓄、债券、基金、股票、房产与其他、加密货币（客观中立） |
| 4 | 指数基金与定投 | 5 | 什么是指数、为什么大多数人跑不赢指数、指数基金是什么、定投微笑曲线、怎么选怎么买（概念） |
| 5 | 资产配置 | 4 | 不要把鸡蛋放一个篮子、股债配置、再平衡、年龄法则 |
| 6 | 避开镰刀 | 6 | 保本高息骗局、荐股群套路、P2P/野鸡交易所、牛市 FOMO、认知偏差清单、遇到可疑怎么办 |
| 7 | 开始行动 | 4 | 先留应急金、清坏债、开账户、小步开始定投、长期主义 |

合计 **34 小节**，每节配 2–3 题测验。

## 5. 非功能需求

| 维度 | 要求 |
| --- | --- |
| 包体 | APK < 8MB（无图片二进制，纯 SVG/代码） |
| 启动 | 冷启动 < 1.5s（本地加载） |
| 权限 | 仅基础权限，**无 INTERNET** |
| 兼容 | Android 7.0+（API 24），覆盖 95%+ 设备 |
| 离线 | 断网飞行模式下全部功能可用 |
| 隐私 | 不采集任何个人信息，无第三方 SDK |
| 横竖屏 | 锁定竖屏（内容阅读体验） |
| 适配 | 沉浸式状态栏、全面屏手势、安全区、不同分辨率 |
| 无障碍 | 触控目标≥44px，颜色不作为唯一信息载体 |

## 6. 交互与状态约定

- 所有可点元素有明显点按反馈（缩放/透明度）。
- 页面切换：淡入上移；Tab 切换即时无动画。
- 数字结果使用滚动动画，≤400ms。
- 错误/完成用 Toast（底部）或内联卡片，不用 alert 弹窗（除危险操作二次确认）。
- 返回键：WebView 历史可回退则回退；否则最小化（系统默认）。

## 7. 数据存储

全部使用浏览器 `localStorage`（WebView 内置），键命名：

| Key | 内容 |
| --- | --- |
| `cxm_onboarded` | "1" 表示已完成引导 |
| `cxm_progress` | `{[lessonId]: 'passed'}` |
| `cxm_quiz` | `{[lessonId]: {best: 100}}` |
| `cxm_risk` | 最近一次风险测评结果类型 |
| `cxm_achievements` | `[id...]` 已解锁徽章 |
| `cxm_streak` | `{last: 'YYYY-MM-DD', days: n}` |
| `cxm_daily` | 当日已签到日期（可选，v1 自动按日期展示） |

## 8. 验收标准

1. APK 可在 Android 7.0+ 设备/模拟器安装并启动，无崩溃。
2. 飞行模式下：引导、34 节课程、全部测验、3 个计算器、风险测评、术语词典、成就、我的 均可正常使用。
3. 学完一章测验通过，下一章自动解锁；进度在杀进程后仍保留。
4. 计算器数值与手算一致（误差<0.1%）。
5. 全应用无任何「买入/卖出/股票代码/加群/微信」类引导。
6. 所有页面存在免责声明或风险提示（工具结果、风险章节等）。
7. 构建产物 `app-debug.apk` 存在且可被 `aapt`/apk 解析。
