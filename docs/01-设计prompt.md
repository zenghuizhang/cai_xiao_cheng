# 财小橙 · 设计 Prompt 与设计系统

> 本文档既是「给设计师/AI 的设计 Prompt」，也是落地实现的设计规范。

---

## 1. 设计 Prompt（可直接用于 AI 出图/出界面）

```
请为一款名为「财小橙」的投资认知启蒙 App 设计移动端界面。

【产品】面向中国投资小白（20-40岁、零理财基础）的纯教育类 App，不交易、不荐股、
不卖课，目标是让用户在投入第一分钱前建立正确认知。
【气质】温暖、可信、轻松、陪伴感；像一个耐心朋友，而非金融机构或券商。
杜绝：黑金高端风、暴涨暴跌的红绿 K 线背景、豪车豪宅暴富暗示、焦虑营销话术。

【吉祥物】一棵叫「小苗」的绿芽：圆润、头顶一片新叶、有简单表情；
在不同场景变换姿势（认真听讲、举手提醒、举盾牌防骗、浇水成长）。

【色彩】
- 主色 成长绿 #2FA877（新芽、复利、安全）
- 主色深 #1F7A56
- 辅色 暖阳橙 #F5A623（关键按钮、进度、强调）
- 警示红 #E5544B（风险提示，克制使用）
- 背景 暖米白 #FAF7F0（不是纯白，减少长时间阅读刺眼感）
- 卡片 纯白 #FFFFFF，圆角 16px，柔和阴影
- 文字 主文字 #2B2B2B、次要 #6B6B6B、占位 #AAAAAA

【字体】中文无衬线（系统默认 PingFang/思源黑体感）；数字等宽用于计算器；
标题 20-24px 半粗，正文 15-16px，行高 1.7。

【组件】
- 底部 3 Tab：学习（小苗路径）、工具箱（计算器/测评/词典）、我的（进度成就）
- 学习路径：竖向时间线 + 章节节点 + 进度环；已完成节点金色对勾
- 课程卡片：大圆角、章节序号圆牌、标题、一句话简介、预计时长、进度条
- 课程正文：卡片式分段；重点句用绿色引用块；术语用下划虚线 + 点按弹出释义
- 测验题：选项大卡，点选后立即反馈（绿对勾/红叉 + 小苗点评），最后给分
- 计算器：大号数字、滑块（橙）、实时结果卡、SVG 折线/柱状图（绿橙对比）
- 空状态/引导：小苗插画 + 一句鼓励 + 主按钮
- 页面切换：左右滑入/淡入 200-250ms，缓动 ease-out

【插画】全 SVG 手绘风扁平插画，绿色为主，线条圆润，
用于：空状态、章节封面、吉祥物、复利增长曲线等。

【可访问性】触控目标≥44px；对比度达标；不单独用颜色传达信息
（对勾/叉号配合颜色）；支持系统字号缩放。
```

## 2. 设计 Token（实现层）

### 2.1 颜色

| Token | HEX | 用途 |
| --- | --- | --- |
| `--brand` | #2FA877 | 主色、导航高亮、正向数值 |
| `--brand-dark` | #1F7A56 | 按下态、深色文字 |
| `--brand-soft` | #E4F4EC | 主色浅底 |
| `--accent` | #F5A623 | 主 CTA、滑块、进度 |
| `--accent-soft` | #FDF1DC | 强调底 |
| `--danger` | #E5544B | 风险/错误 |
| `--danger-soft` | #FCE9E7 | 风险底 |
| `--bg` | #FAF7F0 | 页面背景 |
| `--card` | #FFFFFF | 卡片 |
| `--ink` | #2B2B2B | 主文字 |
| `--ink-2` | #6B6B6B | 次文字 |
| `--ink-3` | #AAAAAA | 占位/禁用 |
| `--line` | #EDEAE2 | 分割线/边框 |

### 2.2 字号与间距

- 字号：12 / 13 / 15（正文）/ 17 / 20 / 24 / 28
- 圆角：8 / 12 / 16 / 999（胶囊）
- 间距基数：4px；常用 8/12/16/20/24
- 阴影：`0 4px 16px rgba(31,122,86,.08)`

### 2.3 动效

| 场景 | 动效 | 时长 |
| --- | --- | --- |
| 页面转场 | 淡入 + 轻微上移 8px | 220ms ease-out |
| 卡片点按 | 缩放 0.98 + 透明度 | 120ms |
| 选项反馈 | 背景色渐变 + 图标弹入 | 200ms |
| 进度环 | stroke-dashoffset 过渡 | 600ms |
| 数字滚动 | requestAnimationFrame 插值 | 400ms |

## 4. 情感化设计要点

- 成就解锁时小苗「长大」一厘米，配撒花动画（纯 CSS/SVG）。
- 测验答错不批评：小苗说「差一点！这里很容易搞混，记住啦～」。
- 风险章节把红色用足，其他章节克制；让红色在该警惕的地方真正醒目。
- 所有数字结果下方必带一句风险提示，避免用户只看到收益数字。
- 首次打开有 3 屏引导：「不荐股」「不碰你的钱」「随时离线」——先建立信任。

## 5. 不做的设计

- ❌ 不用 K 线图作为视觉主体（会让小白紧张，且暗示炒股）
- ❌ 不用红涨绿跌的 A 股配色作为主基调
- ❌ 不做「今日涨幅榜」「热门基金」类模块
- ❌ 不做社区/评论/晒单（避免噪音和误导）
- ❌ 不做任何需要登录的流程
