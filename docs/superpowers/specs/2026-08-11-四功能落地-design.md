## 1. 背景与目标

财小橙 v6（content_version=6）已具备 120 卡 / 32 题 / 231 词条 / 8 模拟 / 16 本书的完整教学内容，测试与构建全绿。但存在 4 个发布前缺口：

| 缺口 | 现状 | 本批目标 |
|---|---|---|
| 引导页 | 首启直接进 MainShell，无介绍 | 3 页滑动介绍，首启一次，完成进主界面 |
| 风险测评 | 完全空白 | 5 题测评 → 风险画像入库 → 影响「我的」页与计算器 |
| 复习队列 UI | review_queue 表有数据无页面（断头交互） | 首页 banner + 卡片流复习 |
| 复利/通胀计算器 | 只有定投计算器 tab | 模拟页新 tab：复利终值 + 通胀购买力对照 |

**顺带修复**：首页段位卡进度条硬编码 `cardsRead / 80`（批 2 后应为 120 张），改为从卡片总数取。

## 2. 架构与数据流

```
┌─ 新用户体验组 ─────────────────────────────┐
│  SplashGate ──onboarding_done 检测──→ OnboardingScreen（3 页）
│                        ↓ 完成（写 onboarding_done=1）
│                        MainShell（4 tab）
│
│  我的-工具箱「风险测评」→ RiskQuizScreen（5 题）→ 结果页（画像+建议）
│                        ↓ risk_profile / risk_taken_at 写入 user_status
│   影响点① 我的页头像区显示画像 chip
│   影响点② 复利计算器页显示「你的类型建议配置」引用条
└──────────────────────────────────────────┘

┌─ 工具增强组 ──────────────────────────────┐
│  首页「待复习 N 张」banner → ReviewScreen（卡片流）
│      右滑/「这次懂了」→ mastered=1 移出队列（+5 积分）
│      左滑/「再想想」→ review_count+1 留队
│  模拟页 tab：模拟人生 / 定投计算器 / 复利计算器（复利+通胀对照）
└──────────────────────────────────────────┘
```

**原则**：
- 测评题库只读 assets JSON（`risk_quiz` 段），不入库——无状态内容，老用户无需热更灌库
- 用户状态（onboarding_done、risk_profile）全部进 `user_status` 表，走 SQLite 版本迁移（4→5）
- 复习队列消费现有 `review_queue` 表，仅补 3 个查询/写入方法
- 卡片滑卡 UI 抽为共享组件，学习页与复习页复用（顺带减少重复）

## 3. 功能细节

### 3.1 OnboardingScreen（引导页）

- 文件：`lib/features/onboarding/onboarding_screen.dart`
- 3 页 `PageView` + 底部指示点 + 「跳过」（右上角）：
  - P1 🍊「你好，我是财小橙」——投资启蒙 App，把金融名词翻译成大白话，从零开始
  - P2 🗺️「四步学习路径」——看懂通胀 → 分清工具 → 掌握定投 → 识破骗局
  - P3 🛡️「三个承诺」——不荐股、不承诺收益、纯教学（细看完整版可到「我的-关于与免责声明」）
- 末页按钮「开始学习」→ 写 `onboarding_done=1` → `pushReplacement` 到 MainShell
- 入口判定：`SplashGate` 加载完成后，`!onboardingDone` → OnboardingScreen
- 文案风格与 App 一致（🍊 语气、AppTheme）

### 3.2 RiskQuizScreen（风险测评）

- 文件：`lib/features/risk/risk_quiz_screen.dart`（题库+测评流程+结果页）
- 题库：`knowledge_base.json` 新段 `risk_quiz`，5 题，每题 3 选项，选项带分值（0/2/4）
- 题目（呼应课程内容，教学+合规双达标）：
  - RQ1 有一笔 3 年后要用的钱，你会怎么放？（存定期/一半存款一半基金/全买指数基金）
  - RQ2 你买的基金跌了 20%，你会？（卖掉止损/拿着等回本/趁便宜加仓）
  - RQ3 你的投资目标是？（保住本金最重要/跑赢通胀就行/希望获得较高收益）
  - RQ4 每个月能投入的闲钱大概占收入？（几乎没有/一成左右/两成以上）
  - RQ5 朋友说有个「高收益稳赚」项目，你会？（直接拒绝/表示怀疑先查查/心动了想试试）
- 评分映射：≤6 保守型 🛡️ ｜ 7–13 稳健型 ⚖️ ｜ ≥14 进取型 🚀
- 结果页：画像 emoji+名称、3 行解读、建议股债配置（保守 20/80、稳健 40/60、进取 60/40——呼应 C3 资产配置卡片）、「再测一次」按钮、页脚「测评结果仅供教学参考，不构成投资建议」
- 存储：`saveRiskProfile(type)` 写 `risk_profile` + `risk_taken_at`
- 入口：我的-工具箱 tile「风险测评」；副标题显示当前画像（已测）或「5 分钟了解自己的投资性格」（未测）
- 重测：随时可从工具箱再进，覆盖写

### 3.3 ReviewScreen（复习队列卡片流）

- 文件：`lib/features/learn/review_screen.dart`
- 首页 banner（每日挑战 banner 下方）：🔁「待复习 N 张」副标题「左滑没懂的卡片，再刷一遍」；N=0 时不渲染（首页干净）
- 卡片流复用学习页交互：`Dismissible` 右滑「这次懂了」/左滑「再想想」，底部按钮同语义
- 数据流：
  - 右滑/懂了 → `recordReview(cardId, mastered: true)`：`UPDATE review_queue SET mastered=1, review_count=review_count+1`；**+5 积分**（复习奖励，标注「复习巩固 +5」）
  - 左滑/再想想 → `recordReview(cardId, mastered: false)`：`UPDATE review_queue SET review_count=review_count+1, mastered=0`（留队）
- 队列顺序：`WHERE mastered=0 ORDER BY added_at`
- 学习页左滑「没懂」入队逻辑补强：卡片若已 mastered，再次左滑 → `UPDATE review_queue SET mastered=0`（重新入队语义）
- 空队列：🎉「全部掌握啦」+ 引导按钮「去学新卡」
- 复习完成页：本轮共复习 N 张，掌握 X 张 + 返回按钮
- 顶部进度：CircleProgress（同学习页样式）+ 复习计数

### 3.4 复利计算器 tab（CompoundCalculator）

- 文件：`lib/features/simulation/compound_calculator.dart`
- `SimulationScreen` `DefaultTabController` length 2→3，新增 `Tab(text: '📈 复利计算器')`
- UI 复用 `_Calculator` 滑块风格（滑块 + 大数字 + 公式说明卡）：
  - 本金滑块：1 千 – 100 万（默认 10 万）
  - 年化滑块：0% – 15%（默认 5%）
  - 年数滑块：1 – 50 年（默认 20 年）
- 输出（复用 `FinanceMath` 现有函数）：
  - 复利终值（一次性投入）
  - 同笔钱按 3% 通胀折算的 20 年后购买力
  - 72 法则提示条：「按 X% 年化，约 Y 年翻倍」
- 若已测评：顶部引用条「⚖️ 稳健型建议：股债 40/60（教学参考）」——影响点②
- 公式说明卡 + 「以上均为假设计算，不构成投资建议」

## 4. 数据层与迁移

### 4.1 SQLite 迁移（_dbVersion 4 → 5）

- `onCreate` 的 `user_status` 建表加三列（新装用户）：
  - `onboarding_done INTEGER DEFAULT 0`
  - `risk_profile TEXT`
  - `risk_taken_at TEXT`
- `onUpgrade` 新增 `if (oldV < 5)`：逐列 `ALTER TABLE user_status ADD COLUMN ...`
- `saveUserStatus` 是 patch 式 map UPDATE，新列天然支持；`getUserStatus` 通配查询自动带出新列
- `AppState` 增加 `onboardingDone`、`riskProfile`、`reviewCount` 字段，`refresh()` 读取

### 4.2 DatabaseHelper 新方法

- `getReviewQueue()` → `List<Map>`（mastered=0 按 added_at）
- `recordReview(String cardId, {required bool mastered})` → 更新队列 + 积分（mastered 时 +5，积分走 totalPoints 汇总）
- `saveRiskProfile(String type)` → user_status 写 `risk_profile` + `risk_taken_at`

### 4.3 内容版本

- `knowledge_base.json`：新增 `risk_quiz` 段（5 题），`meta.content_version` 6 → 7
- 题库不入 DB（测评页直接 rootBundle 读 JSON），老用户无需重灌
- 代码侧 `_contentVersion` 常量不动（与 JSON meta 的同步是既有状态，不在本批范围）

## 6. 非目标（本批不做）

- 复习的间隔重复算法（SM-2 等）——队列顺序固定为入队先后
- 测评结果影响学习解锁/章节推荐（只影响展示层：我的页 chip + 计算器建议条）
- 引导页「再看一遍」入口
- 首页 cardsRead 硬编码之外的其它文案审计（如「我的」页副标题「69 个金融词」「12 本投资经典」——数量文案顺带同步为 231/16）
- 内容热更灌库机制（onUpgrade 按 content_version 重灌）——保持现状，列为已知边界
