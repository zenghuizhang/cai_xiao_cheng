# 财小橙 · 产品定位文档

> 一款为「投资小白」建立正确投资认知的移动应用（Android APK）。

---

## 1. 一句话定位

**财小橙** 是一个陪伴式的投资认知启蒙工具：不荐股、不跟单、不碰你的钱，只帮你在投入第一分钱之前，建立能保命的投资常识。

> 「种下一粒财商的种子，陪你慢慢长大。」

## 2. 目标用户画像

### 2.1 核心人群

| 维度 | 描述 |
| --- | --- |
| 年龄 | 20–40 岁 |
| 身份 | 职场新人、年轻白领、宝妈、学生党 |
| 特征 | 有一点积蓄（几千到十几万），收入稳定但不知如何打理 |
| 痛点 | ① 觉得投资=炒股=赌博；② 被「余额宝收益越来越低」焦虑；③ 看不懂术语、不敢开始；④ 怕被割韭菜、怕被骗；⑤ 跟风买过基金/股票，亏了也不知道为什么 |
| 场景 | 通勤地铁上、睡前、发工资后、看到「暴跌」新闻时 |

### 2.2 用户最想说的三句话

1. 「我不是想暴富，我只是不想让钱贬值。」
2. 「那些 K 线、PE、定投……能不能用人话讲？」
3. 「我怎么知道自己正在被骗？」

## 3. 核心价值主张

| 价值 | 说明 |
| --- | --- |
| **安全第一** | 全程教育内容，无交易、无开户导流、不收集隐私；不制造暴富幻想 |
| **说人话** | 每个术语都配比喻和例子，像朋友聊天而不是教科书 |
| **成体系** | 从「为什么要理财」到「怎么迈出第一步」，7 章闭环，不再东拼西凑看碎片文章 |
| **动手玩** | 复利、通胀、定投都能拖一拖滑块亲眼看到结果，认知来自体感而非死记 |
| **防镰刀** | 单设「韭菜自救手册」，把常见骗局和认知偏差讲透 |

## 4. 与竞品的差异

| 类型 | 代表 | 它们的问题 | 财小橙怎么做 |
| --- | --- | --- | --- |
| 理财社区/雪球类 | 雪球、股吧 | 信息噪音大、容易追涨杀跌 | 不做社交、不晒收益，只给结构化知识 |
| 基金销售平台 | 蚂蚁财富、天天基金 | 立场是卖家，倾向于让你买 | 不卖任何产品，无商业立场 |
| 付费财商课 | 长投、微课 | 贵、营销重、动辄「逆袭」 | 免费、离线、无广告，反焦虑 |
| 短视频财经 | 抖音财经号 | 碎片化、标题党、真假难辨 | 体系化路径 + 互动测验巩固 |

## 5. 产品原则（不可妥协）

1. **不构成投资建议**：所有内容标注「教育用途」，不预测市场、不推荐具体标的代码。
2. **诚实面对风险**：不回避亏损的可能，明确展示「收益与风险并存」。
3. **小白友好**：默认用户什么都不懂；任何专业词第一次出现必须解释。
4. **3 分钟一节课**：单节内容控制在 3–5 分钟可读完，符合碎片场景。
5. **离线可用**：内容全部内置，无网络也能用——同时传递「我们不追踪你」的信任。
6. **温暖不焦虑**：不用「暴跌」「血亏」「快上车」这类词，不制造恐慌或 FOMO。

## 6. 成功指标（产品自评估，无需埋点）

- 用户完成至少 1 章测验并通过 → 认知闭环成立
- 工具页（复利计算器）被使用 → 「体感式学习」成立
- 风险测评完成后给出配置概念 → 帮助用户认识自己
- 全程无任何「买/卖/代码/群」入口 → 安全信任成立

## 7. 商业模式与边界

- 当前版本：**纯公益/工具型**，无广告、无内购、无账号、无数据上报。
- 未来若扩展，也不得：代客理财、荐股、承诺收益、售卖「带单」服务。
- 唯一可接受的方向：付费的体系化深度课程（仍为教育内容，非投顾）。

## 8. 品牌识别

- **名称**：财小橙（CaiXiaoCheng）
- **吉祥物**：小苗——头顶一片嫩叶的小绿芽，表情随场景变化（认真、开心、警惕、鼓励）
- **Slogan**：从零开始，慢慢变富
- **色彩性格**：成长绿 + 暖米白 + 提醒橙/警示红，柔和不刺眼
- **语气**：像一个耐心、靠谱、稍微有点幽默的朋友
