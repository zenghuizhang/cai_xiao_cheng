# 财小橙 · 项目拆解与落地计划

## 1. 技术选型决策

| 选项 | 评估 | 结论 |
| --- | --- | --- |
| 原生 Kotlin + Compose | 体验最好，但 UI 代码量大、Kotlin 插件/KSP 依赖多、内容富文本排版麻烦 | ❌ |
| Flutter / React Native | 需安装额外 SDK，构建链重、下载量大 | ❌ |
| 微信小程序 | 无微信开发者工具 CLI 可验证；且需微信账号/审核 | ❌（本次环境） |
| **原生 Java + WebView + 本地 H5** | 原生壳只需 1 个 Activity，内容用 HTML/CSS/JS 快速迭代；依赖最少（AGP/JDK 已缓存）；APK 小、离线、可真机构建验证 | ✅ |

> 选型原则：**能在本环境真正构建出 APK 并验证**，同时保证内容与 UX 质量。H5 部分用纯手写（无框架、无构建步骤），零网络依赖，最可靠。

## 4. 关键实现说明

### 4.1 为什么无网络权限
- `<uses-permission android:name="android.permission.INTERNET"/>` 不声明。
- 内容全部在 `assets/www`，WebView 用 `file:///android_asset/www/index.html` 加载。
- 既减小攻击面、保护隐私（信任卖点），也保证飞行模式可用。

### 4.2 WebView 安全设置
```java
webView.getSettings().setJavaScriptEnabled(true);
webView.getSettings().setDomStorageEnabled(true);       // localStorage
webView.getSettings().setAllowFileAccess(false);
webView.getSettings().setAllowContentAccess(false);
webView.getSettings().setBlockNetworkLoads(true);      // 双保险：禁止任何网络
webView.setWebViewClient(new WebViewClient());         // 不跳外部浏览器
```

### 4.3 图表方案
不引入图表库（避免依赖和体积），用纯 JS 生成 SVG path：
- 复利：折线 + 本金/收益面积分层
- 定投：年末对比柱 + 折线
- 坐标、刻度、数值 tooltip 自己计算

### 4.4 内容数据格式（JS 对象示例）
```js
{ id:'3-2', chapter:3, title:'基金：把钱交给专业的人', minutes:3, level:2,
  blocks:[
    {type:'hero', text:'想象一群人凑份子吃饭……'},
    {type:'p', text:'基金就是把很多人的钱凑起来……'},
    {type:'point', text:'基金本质是「委托理财」，赚亏都算你自己的。'},
    {type:'p', text:'基金经理负责投资，但{不保证赚钱}。', terms:['基金经理']}
  ],
  quiz:[
    {q:'关于基金，下列哪个说法正确？',
     options:['买基金一定能赚钱','基金是把钱凑起来委托专业机构投资','基金保本保息'],
     answer:1, explain:'基金不保本也不保息，它是一种「代客理财」的投资工具。'}
  ]
}
```

### 4.5 解锁规则
- 小节按顺序解锁；章节按顺序解锁。
- `store.isLessonUnlocked(lessonId)`：上一节已通过，或它是本章第一节且上一章全部通过。
- 第一节课默认解锁。

### 4.6 金融计算口径
- 复利：年复利 `FV = PV*(1+r)^n + PMT*(((1+r)^n -1)/r)*((1+r)/1?)` —— 采用「月末定投、年化收益率」标准年金公式，月利率 = 年化/12，月数 = 年数*12。
- 定投：同一年金终值公式。
- 通胀：未来购买力 = 金额 / (1+通胀率)^年数。
- 全部为名义收益示例，页面明确注明非预测、非建议。

## 5. 验证清单（完成定义 DoD）

1. `gradle assembleDebug` 退出码 0；
2. `app/build/outputs/apk/debug/app-debug.apk` 存在且大小合理；
3. `aapt dump badging` 能解析包名、版本、图标、启动 Activity；
4. APK 内 `assets/www/` 含完整 HTML/CSS/JS；
5. 反查 APK 清单确认无 `INTERNET` 权限；
6. JS 语法通过 `node --check`；
7. 文档 4 份齐全，README 说明清晰。
